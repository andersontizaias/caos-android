# Caos Android

[![CI](https://github.com/andersontizaias/caos-android/actions/workflows/ci.yml/badge.svg)](https://github.com/andersontizaias/caos-android/actions/workflows/ci.yml)
[![Lint](https://github.com/andersontizaias/caos-android/actions/workflows/lint.yml/badge.svg)](https://github.com/andersontizaias/caos-android/actions/workflows/lint.yml)
[![License](https://img.shields.io/badge/license-MIT-lightgrey)](LICENSE)

Port em Jetpack Compose do [Caos](https://github.com/andersontizaias/Caos) (SwiftUI) — um framework
de Server-Driven UI que gera telas a partir de arquivos YAML, sem redeploy do app.

**Status:** `caos-core`, `caos-compose`, `caos-lint` e `caos-sample` implementados (Fases 1–5 do
[`PLAN_ANDROID.md`](./PLAN_ANDROID.md)); documentação completa (README espelhando o do Swift,
`CHANGELOG.md`) é a Fase 6, ainda pendente.
